# v0.3.1 界面与调度验证

本记录针对当前修改，不替代历史原生后端验证。测试只使用仓库合成语音，不包含个人录音。

- 72 项离线测试通过：默认三个池均为 4；12 个请求同时提交时运行 8、排队 4；单池配置为 42 时也不能突破全局 8 路；局部队列不会预占全局额度；取消等待会清理计数与额度。
- 模型列表只包含 `wechat-voice`、`wetype-voice`、`doubao-voice`。旧别名请求和未填写 model 均被拒绝，OpenAPI 不再提供默认 model。
- 未启用鉴权时，无 Authorization、空值及任意 Bearer/Basic 值均可调用。桌面改为显式鉴权开关；旧版已加密保存的非空密钥保留鉴权，避免升级时关闭既有保护。
- 原生 Tk 窗口渲染已检查首页和手动转写页；96/120/144/192 DPI 的最小与加大窗口布局检查通过，包含顶部导航、文档按钮及结果区域。
- Windows x64 免安装包构建成功。实际 EXE 的依赖自检和 8 项托盘/服务生命周期检查通过，包括关闭鉴权后忽略任意 Key、修改闲置 Key 不重启、开启鉴权、密钥轮换、加密持久化、托盘恢复与正常退出。托盘检查调用已注册菜单回调，没有执行物理鼠标点击。
- 实际打包 EXE 同时提交微信输入法 2 路和豆包 2 路，共 4 个请求全部 HTTP 200，识别文本与合成样本相符。观察到两池各占用 2 路；结束后格子和排队归零，测试服务正常停止。输入法结束标志为 `server_end_flag`，豆包为 `final_and_session_finished`。
- 微信桌面端未运行，本轮未重新进行微信真实识别；全局 8 路限制由离线受控后端验证，不代表真实上游已通过 8 路压力测试。
- ZIP CRC、资源清单和 SHA-256 校验通过。构建产物、机器信息及原始运行报告不进入源码提交。

已有自定义并发设置会保留；新安装默认值为每池 4。所有配置均受全局 8 路运行限制。
