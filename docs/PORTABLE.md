# Windows 免安装窗口版

无需安装 Python、conda 或 FFmpeg。程序仍需要本机已安装并登录 **微信 4.1.13.65**，且账号启用微信的 iLink/Opus 语音识别能力；其他微信版本需要重新适配，不会绕过版本核验。

## 开始使用

1. 下载 `WeChatASRBridge-0.2.3-windows-x64-portable.zip`。
2. 把整个 ZIP 解压到任意普通文件夹。保留 `_internal` 文件夹，不能只移动 EXE。
3. 登录微信，双击 `WeChatASRBridge.exe`。
4. 点击「启动服务」。如果本机已有兼容桥接服务，窗口会直接连接它。
5. 点击「使用示例音频」或「选择音频」，然后点击「开始识别」。结果可以复制或另存为 TXT。

音频通过已登录的微信客户端发送到微信服务端，不发送到 OpenAI。单个文件最大 25 MiB，已验证 WAV/MP3；其他格式通过内置 FFmpeg 解码。识别最多 4 路并发，多出的请求排队。

## 接入其他程序

| 配置 | 默认值 |
| --- | --- |
| SDK Base URL | `http://127.0.0.1:8765/v1` |
| Screenpipe Endpoint | `http://127.0.0.1:8765` |
| API Key | `wechat-local` |
| 模型 | `wechat-voice` 或 `whisper-1` |

窗口里的「复制 SDK 地址」可以复制完整 Base URL。「接口文档」打开本机 Swagger 页面。默认仅本机访问，窗口不提供聊天、翻译、流式语音或 Realtime API。

需要调整端口或连接已设置鉴权的现有服务时，点击「连接设置」，填写端口或 API Key。端口和密钥会记住；密钥通过 Windows DPAPI 加密，只能由当前 Windows 用户解密。填写非空密钥后，由本应用启动的服务会启用鉴权；更改已运行的自有服务的端口或密钥时，会等待请求完成并重新启动服务。

## 后台运行和停止

关闭窗口后，应用隐藏到系统托盘，由本应用启动的接口服务会继续在后台运行，Screenpipe 可继续调用。双击托盘图标或选择「显示窗口」恢复窗口；要停止服务，请点击「停止服务」。托盘菜单的「退出」会停止由本应用管理的服务，并退出应用。停止或退出会等待已提交请求和会话清理完成，不会强杀微信；识别中关闭窗口也会保留结果。

其他程序启动的已有服务只能在此窗口查看和调用；请使用原来的停止方式管理，避免误停 Screenpipe 的服务。

日志与服务控制文件位于 `%LOCALAPPDATA%\WeChatASRBridge\runtime`，通过「打开运行日志」查看。ZIP 中不会保存账号信息、用户录音或识别结果；结果只有点击另存为时才写入所选文件。

## 更新和故障

- 更新时先停止旧服务，再解压新版 ZIP；不要在旧服务运行期间删除它所在的文件夹。
- 显示端口被占用时，确认是不是已运行的桥接；其他程序占用时可更改端口，并同步修改客户端地址。
- 显示 DLL 指纹不匹配时，确认微信版本为 4.1.13.65。微信自动更新后可能需要新的适配版本。
- 显示会话清理失败时，退出微信后重新登录，再启动服务。
- 显示微信连接已中断时，退出微信后重新登录；清理状态未知的同一微信进程会暂停调用。
- v0.2.2 的回调入口在脚本卸载后仍有效；原生会话取消后等待任务释放引用再析构，避免仅靠固定延时判断清理完成。
- v0.2.3 将左下角四个按钮的两排保持紧凑，拉高窗口不会再扩大两排间距，并包含 v0.2.2 的原生生命周期修复。
- 实验桥接使用微信原生调用。当前验证覆盖并发、长音频和正常停止，尚未进行长期持续并发压力测试。
